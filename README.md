# Andice的共用畫板（師生共用數位白板）

- 老師端：https://andice0107.github.io/class-whiteboard/
- 學生端：https://andice0107.github.io/class-whiteboard/play.html （掃老師畫面上的 QR code 進入，再輸入教室代碼與數字學號）

功能（第一版）：開教室（每次新代碼）、學號只能輸入 1～6 位數字、簡報模式即時同步、作業模式每組各自的畫板、老師多色筆／學生黑筆、上一步、局部橡皮擦（學生擦不掉老師的筆劃）、全消除、多頁畫板、監控牆全開／全關、老師進入學生畫板協作、分享某位學生畫面給全班、畫筆權限全開／全關／個別開關。

連線使用免費公開 MQTT 中繼站，不需帳號。所有內容存在老師這台裝置的瀏覽器中。
